# SPD Box QP PCG Generalization Research

This project investigates the claim:

> Can most or all QP problems be reformulated as strictly convex SPD box QPs and then solved accurately and robustly by PCG?

The answer is tested through:

1. mathematical classification of QP structures,
2. small counterexample experiments,
3. validation of the robot drift free Method3 case where the SPD box QP structure is genuinely matched.

Main outputs:

- `docs/research_report.md`
- `results/synthetic_qp_generalization_summary.csv`
- `results/synthetic_qp_generalization_report.md`
